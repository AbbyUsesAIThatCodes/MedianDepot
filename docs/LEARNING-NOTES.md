# Learning Notes

This original cargo activity supports measures-of-center practice for **DM 1.3 Measuring Matters** and **DM 1.4 Skimmer Statistics**. It uses invented quantities, not collected flight measurements or reproduced PLTW exercises. Existing public curriculum adaptations remain planning context; no proprietary curriculum text or assets are embedded.

The student orders intact observations, includes repeated values and explicit zero, identifies the positional center, and averages both middle quantities when there are two. The example 0, 2, 3, 8 has median (2 + 3) / 2 = 2.5. The median need not be an observed value. The example 0, 2, 4, 4, 7, 9 still has two distinct middle observations, even though their quantities match.

A shared factory world helps connect this to MeanMachine, but the mathematical actions differ: MedianDepot preserves every observation while sorting; MeanMachine redistributes quantity to model equal sharing. Pair guides and completion feedback are practice supports, not proof of independent mastery.

The game does not by itself assess physical measurement, units and precision, collection of student trials, spreadsheet/chart skills, spread, rounding a reported mean, or a written explanation. Guided Example Mode, a separate Challenge Mode, classroom-device acceptance, and worksheets remain later work.
